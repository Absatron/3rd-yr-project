> > > I have set up your IT username on the CSF3. Please see our getting started guide for login and essential information: https://ri.itservices.manchester.ac.uk/csf3/getting-started/

The 10-minute batch job tutorial is highly recommended, as the batch system is the main way jobs are run on the CSF3. Explore the tabs on the website for more detailed information.

There is no limit on the number of CPU jobs you can submit, you can use up to 4 GPUs. The system can get busy, so it is best to submit work steadily, rather than waiting to run everything at once.

Many software applications are already installed as modules, but a specific version you have been using on your own computer may not be present. Please try an installed version before asking for a new installation as it can take time to make new software available. A list of installed software and guidance to install software yourself can be found on our software pages: https://ri.itservices.manchester.ac.uk/csf3/software/#Installing_your_own_Software

You must not use CSF3 for processing sensitive data.

Because storage in your home space is limited, run jobs from the large, high-performance ‘scratch’ filesystem. Note that scratch is not backed up and has an automated clean-up policy: https://ri.itservices.manchester.ac.uk/csf3/filesystems/scratch-cleanup/

For safe long-term storage, use a research data storage (RDS) location. Further information on the RDS pages: https://ri.itservices.manchester.ac.uk/rds/

Many of our users acknowledge the CSF in their publications and other outputs, you can find suggested acknowledgement text on our website: https://ri.itservices.manchester.ac.uk/csf3/overview/ack/

If you need help, please submit a support form: https://ri.itservices.manchester.ac.uk/csf3/overview/help/
